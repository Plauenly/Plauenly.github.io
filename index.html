二、算法理解

TOOD（Task-aligned One-stage Object Detection）

专门用于单阶段目标检测的具体算法。核心思想是解决单阶段检测器里一个经典问题：分类任务和定位任务的不对齐。

SeViL 的 TATE 阶段

在 TATE（Text-guided Adaptive Target Enhancing）阶段我有些疑问：获得注意力权重 G 并作用到 motion features M 以后，源代码是怎么做的（即下一步检测头是怎么做的）？

答案：直接把增强后的特征当作普通的 FPN 特征来用。

GMM（Gaussian Mixture Model）

源代码如何实现？核心是使用现成的 sklearn.mixture.GaussianMixture。

  • 流程：在每个 batch 中去统计，获得一个阈值，过滤出所有高于阈值的用于学生模型的训练。
  • 原理：初始化两个得分最高的与得分最低的，去用算法演化，默认阈值取正样本中的峰值。

Mask 与恢复

对象 策略
文本 prompt 15% 的向量置 0
图像特征 2×2 块，25% 置 0

恢复方式：RecoverText 使用交叉注意力，RecoverImage 拼接 + 两层卷积。

新的认识：1:9 mask 与三路增强

在 dataset 阶段，原始数据的位置标注信息被故意按 1:9 mask 了：

  • 拿 1 个 labeled 作为有监督，另外 3 个 unlabeled 作为无监督；
  • 每个以它为结尾抽取最相邻的 4 帧一起（因为最终使用的是融合后的最后那帧）作为输入样本；
  • 并根据「是否进入学生模型」与「是否有监督」做相应的增强；
  • 一个样本的 5 帧共享同一套增强参数，保证了几何/颜色增强在帧间是一致的。
分支 增强策略

unsup_teacher 只有 RandomResize
unsup_student RandomResize + RandomOrder（RandAugment 颜色，RandAugment 几何）

四、训练与调试要点

iter 与 epoch

  • 1 个 iter = 1 次前向 + 反向（1 个 batch）
  • 1 个 epoch = 完整遍历一遍训练集
  • 对于大数据集 / 长训练，通常按 iter 级别而不是 epoch 级别来训练，因为改数据集大小不影响总训练量。

训练命令

带 resume 和 cfg-options、并只看 debug 输出：

python xxx.py 与 python -m xxx

python -m mymod 当前工作目录

Docker 学习

一条命令看懂 run 的各个参数

  • --name：给容器起名字（等同于用容器 ID 的功能）
  • -e：给定环境变量
  • -d：在后台运行
  • -p 80:80：把宿主机的 80 端口映射到容器的 80 端口
  • --network network1：加入子网 network1（也可用 host 直接用宿主机网络）
  • --restart unless-stopped：只要不是手动停止容器，都会自动重启
  • -v：把宿主机的目录与容器内的目录进行绑定

基本概念

  • Dockerfile 是镜像制作的图纸，镜像是容器的模具。
  • 可以设置每个容器里的 CPU、内存、网络带宽等资源上限（cgroups）。

nginx 学习

HTTP 协议默认端口是 80，所以不输入端口号就默认访问 80 端口。

nginx 配置文件的 server 块里连接的文件根目录，就在配置文件所在的目录。

执行 docker exec nginx nginx -s reload 时：如果新的 nginx.conf 有语法错误，reload 会失败，但旧的 worker 会继续用老配置运行——服务不会挂，但你改的东西没生效。

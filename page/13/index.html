JWT 与微信支付整体流程

发表于 2026-07-30 更新于 2026-10-09

JWT 是什么

JWT（JSON Web Token）是一种紧凑的、自包含的网络身份认证令牌标准。简单说，它利用签名技术（注意：主要载荷并没有加密，只是 base64 编码）在各方之间安全地传递可验证的信息，比如用户身份。

登录流程

  1. 前端在进入小程序时调用 wx.login() 获得 code。
  2. 后端拿着 code 访问 https://api.weixin.qq.com/sns/jscode2session，获得 openid（永久不过期，同一小程序内不变）。
  3. 把用户信息做成 JWT token 返回，小程序端一直保存着这个 token。

支付流程

  1. 后端收到支付请求后，调用 https://api.mch.weixin.qq.com，传入商户相关信息、支付金额以及支付者的 openid。
  2. 成功后收到 prepay_id，用它和自己的商户私钥生成相应的信息包。
  3. 小程序中把该信息包传入 wx.requestPayment，即可唤起支付页面。
  4. 支付成功后，微信会以 POST 形式通知 https://你的域名/pay/notify。

注意：微信支付官方主要支持 IPv4。

HTTP 状态码速查

1xx 信息响应

状态码 含义
100 Continue 服务器已收到请求的一部分，客户端可以继续发送其余部分。
101 Switching Protocols 服务器正在根据客户端的请求切换协议。

2xx 成功响应

状态码 含义
200 OK 请求成功，服务器返回了请求的数据。
201 Created 请求成功，并且服务器创建了新的资源。
204 No Content 请求成功，但响应主体中没有新的数据。

3xx 重定向消息

状态码 含义
301 Moved Permanently 请求的资源已永久移动到新网址。
302 Found 请求的资源临时移动到新网址。
304 Not Modified 资源没有被修改，浏览器可以使用缓存的内容。

4xx 客户端错误

状态码 含义
400 Bad Request 请求有语法错误，服务器看不懂。
401 Unauthorized 请求需要用户的身份验证。
403 Forbidden 服务器拒绝执行该请求，没有权限。
404 Not Found 找不到请求的网页或资源。

5xx 服务端错误

状态码 含义
500 Internal Server Error 服务器内部出错了，无法完成请求。
502 Bad Gateway 网关或代理服务器从上游服务器收到了无效的响应。
503 Service Unavailable 服务器目前无法使用（超载或维护）。

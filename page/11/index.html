asyncio 与 FastAPI 并发模型

发表于 2026-07-31 更新于 2026-10-09

事件循环与 asyncio

asyncio.run() 会创建一个 event loop，把 main() 协程作为循环上的第一个任务运行；当 main 执行完毕后，自动关闭并清理该 event loop。

FastAPI 的并发模型

uvicorn 服务器会调用类似 asyncio.run() 的机制，启动一个长期运行的事件循环。

  • 在 FastAPI 中，被路由注册的异步函数都是这个 event loop 的协程函数。
  • 当某个协程因为 IO 操作阻塞时，event loop 会让它挂起，并从就绪队列中取出新的协程函数执行。
  • FastAPI / uvicorn 的默认模式是单线程 + 协程并发：在单线程上利用 CPU 与 IO 同时执行的原理，实现函数异步执行。

注意：FastAPI 中只能有一个事件循环，也就是 uvicorn 自己创建的那个。

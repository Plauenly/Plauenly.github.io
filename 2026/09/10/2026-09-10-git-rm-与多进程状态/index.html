git rm 与多进程状态

发表于 2026-09-10 更新于 2026-10-09

git rm –cached

效果：文件不再被 Git 跟踪（会从暂存区移除），但本地磁盘上的文件还在。常用于把已跟踪的文件加入 .gitignore。

查看系统信息

多进程下的静态变量

单进程状态下的顶层代码（缩进为 0 的代码：包括函数、类的定义，静态变量的创建，以及 import 语句）只会执行一次；但在多进程下，每个进程都会保留一个静态变量的副本。

所以多进程之间的通信或许就需要借助 Redis。

多级排序

MySQL 完全支持多字段嵌套排序（也叫多级排序、复合排序）：在 ORDER BY 后面依次列出多个字段，每个字段可以单独指定 ASC（升序）或 DESC（降序）；LIMIT 1 表示只取 1 行。

pydantic alias 机制的坑

  1. FastAPI 默认 response_model_by_alias=True，也就是说响应默认会用 alias。
  2. 而 model_dump() / model_dump_json() 手动序列化时，Pydantic v2 默认 by_alias=False，输出的是字段名，需要显式指定 by_alias=True。

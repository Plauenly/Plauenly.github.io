变量与环境变量

$ 被称作展开运算符。

  • 已导出的变量称为环境（env）变量，未导出的变量称为 shell 变量。
  • shell 变量只在当前进程的 shell 中生效；可以用 export 命令把 shell 变量提升为 env 变量。

export 只能从父进程往子进程方向传递，而不能反向。

Linux 中「环境」的定义

  1. 存储变量名到值的映射
  2. 只属于创建它的那个 shell 进程
  3. 存储文本值变量
  4. 并不共享的全局状态

C 语言中的环境变量

envp 称为环境指针，它是一个以空字符结尾的字符串数组，每个值都表示 key=value。

PATH

系统维护一个「每次搜索程序都在这些目录中查找」的简短列表，叫做 PATH，并把它作为一个环境变量暴露出来，这意味着我们可以修改它。

  • 每当 shell 需要检索一个程序时，会在 PATH 上依次检索，并在找到第一个匹配项时停止并返回。
  • PATH 是一个以 : 作为分隔符的字符串。

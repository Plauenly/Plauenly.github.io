推送遇到的两个坑

1. 22 端口被拒

表现为 git push 卡死。解决办法：在 ~/.ssh/config 中配置改用 443 端口。

2. 用户名密码登录报莫名其妙的错

原因是 GitHub 现在只支持 token 登录或 SSH 方式推送。解决办法：

先用 ssh-keygen 生成自己的公钥与私钥，再把公钥添加到 GitHub 账号中。
